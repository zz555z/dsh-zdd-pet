# dsh-zdd-pet 🐾

一只住在 DeepSeek Harness 里的桌面宠物，一百余个透明动画，可多开、能上桌面。

> 本包是 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的二次开发分支。

## 本分支新增

- **气泡任务进度**：跟随 DSH 任务，气泡实时显示清单进度（`▰▰▱▱▱ 2/5`）；工具调用不再吞掉进度，清单勾选即时更新，有任务时优先不被顶掉。
- **番茄钟（右键菜单 + 常驻倒计时）**：右键菜单可开始专注 / 暂停 / 继续 / 跳过 / 结束 / 重置；专注期间气泡常驻显示倒计时（不闪、不随鼠标移开消失），专注→休息自动衔接，设置页可配专注/休息/长休息时长与轮数。
- **等待确认气泡**：遇到需要用户确认的操作（权限申请 / 向你提问）时，桌宠弹一个带表情的常驻气泡，一直挂到你做出选择为止（不会自己消失）。
- **任务彩蛋**：完成 / 出错时配表情包 + 一句话。
- **余额告急演出**：额度快用光时演一段（三层防刷屏，只弹一次）。
- **启动吉祥话**：每次 DSH 启动说一句吉利话；「语言池」(预生成后随机抽)/「实时生成」两种模式，可开关与配置。
- **气泡表情包总开关**：一个开关统一控制所有气泡是否配表情包（碎碎念/对话/番茄钟/彩蛋/余额/吉祥话/确认）。
- **点击台词**：点宠物时从 `clickTexts` 随机说一句气泡。
- **心情系统**：摸它会涨、久不理随时间自然衰减，分「低落 / 平常 / 开心」三档，影响点击台词语气与空闲动作（开心会撒娇、低落更易叹气）；数值与参数在设置页「心情」区可调（`mood`）。
- **亲密度阶段**：在心情数值上再切「陌生 / 熟悉 / 亲近 / 默契」四阶段，越亲密点击台词越亲昵；每阶段可设「纪念日」，首次达成的周年当天自动演出（`intimacy`）。
- **满格碰撞彩蛋**：心情点满 100 时，宠物按当前位置朝**对角方向**斜冲一下（右下角就往左上、左上角就往右下……），力度每次随机，撞墙/撞角处炸开暖色粒子，弹回后心情随机回落到 61~99。
- **随机小事件**：空闲时每隔一段随机时间自己做个动作（伸懒腰 / 张望 / 打哈欠…），偶尔配一句话，不靠触发也有生命力（`idleEvents`）。
- **任务完成庆祝**：一轮任务成功完成时播专属庆祝动画（`celebrate`）。
- **位置与气泡优化**：四角按宠物身体贴边（`marginX/marginY` 即身体到屏幕边缘像素）；顶部角气泡改为侧弹，不被屏幕裁切。

## 安装

本 fork 已把构建好的 `lib/` 提交进仓库，**可直接从 GitHub 安装、无需构建**：

```bash
dsh plugin --profile desktop add "github:zz555z/dsh-zdd-pet#path:/dsh-zdd-pet"   # web 模式改 web
# 桌面应用：在「插件」页填 github:zz555z/dsh-zdd-pet#path:/dsh-zdd-pet
```

装完重启 DSH。若提示缺运行时依赖，进 `node_modules/dsh-zdd-pet` 跑 `npm install` 再重启。
源码安装：clone → `cd dsh-zdd-pet && npm install && npm run build` → `dsh plugin add file:/绝对路径/dsh-zdd-pet/dsh-zdd-pet`。
